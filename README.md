# undergrad_project
GitHub repository for Clustering High-Dimensional Biomedical Data, 
Fergus Fleming. 

The simulations were completed in AlgorithmComparisonSim. Additional 
visualisations from Visualise.

Parameter matrices were generated manually, and saved locally. Then from these
matrices, the Splatter package was used to generate counts data typical of
scRNA-seq data. 

These were clustered and scored, being saved out locally at each stage between. 

Finally, boxplots were made for inclusion in the final presentation, and summary
statistics used to make the overview tables present in the results section.
